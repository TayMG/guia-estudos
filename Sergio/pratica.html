Prática: do zero ao primeiro popleft()

Esta é a sequência que você precisa saber executar e explicar. Cada comando vem com o motivo de existir — porque na banca você não vai só digitar, vai justificar.

Antes de tudo: o que você precisa ter

Python 3.10+ (o projeto não fixa versão), Git, uma conta no Supabase e um terminal. No Windows, os comandos de ativação da venv são diferentes; estão indicados abaixo. O projeto foi escrito para rodar com internet, porque o banco fica na nuvem.

O requirements.txt tem streamlit, supabase, python-dotenv e faker, mas não tem pandas. O Streamlit instala pandas como dependência transitiva, então pode funcionar por acidente. Em um ambiente limpo, instale explicitamente — ou o import pandas do gerenciador_filas.py pode falhar.

3. Configurar o .env

Copie o exemplo e preencha com a URL e a chave do seu projeto Supabase:

cp .env.example .env       # Windows: copy .env.example .env
SUPABASE_URL=https://SEU-PROJETO.supabase.co
SUPABASE_KEY=sua-chave-publica-aqui

Não use a chave que aparece no README do repositório. Ela é pública por natureza, mas o projeto não é seu e as políticas estão abertas. Crie um projeto novo, com as suas credenciais. O arquivo .env não deve ir para o Git.

4. Criar o schema no Supabase

No dashboard do Supabase, abra SQL Editor e execute o conteúdo de supabase/setup_supabase.sql. Ele é idempotente: cria o tipo status_senha, as tabelas tipo_prioridade, motivo_prioridade, clientes_fila e atendimentos, o índice parcial, as views e as políticas de RLS, e insere o seed.

5. Gerar clientes com Faker

O script aceita a quantidade como argumento. O padrão do main é 20; a função tem 50; o documento fala em 500. Use 500 para testar volume:

python gerar_clientes.py 500

Ele sorteia a categoria com pesos 15/35/50, gera nome, CPF e data de nascimento com Faker pt_BR, e insere em lotes de 25 via supabase-py. O campo data_chegada não é enviado; o banco usa now(). Se você rodar duas vezes, os clientes se acumulam — não há ON CONFLICT para CPF.

Quer ver os dados sem inserir?

Abra um Python interativo e chame gerar_cliente(). Ele devolve um dicionário; não toca no banco. É útil para explicar a distribuição sem depender de rede.

python -m unittest testes_frente2.py -v

7. Rodar o gerenciador e o algoritmo

Os dois arquivos têm um bloco if __name__ == "__main__" que carrega do Supabase e imprime 12 chamadas. Eles precisam de .env e de rede:

python gerenciador_filas.py
python Alexandre.py

O gerenciador_filas.py tem o bloco __main__ duplicado; a função roda duas vezes. Não é fatal, mas é um sinal de descuido. O Alexandre.py tem uma segunda classe GerenciadorFilas completa, que não é usada pelo gerenciador principal — só a função aplicar_starvation é importada.

        9. Streamlit: o que roda e o que não roda

        O README manda rodar streamlit run app.py, mas não existe app.py. O arquivo é streamlit.py. Tente:

        streamlit run streamlit.py

        Se funcionar, você verá “Sistema de Gerenciamento de Fila Bancária”, um aviso de conexão e dois números: categorias configuradas e clientes na fila. Não há botão de chamar. Se der erro de AttributeError no import streamlit, é o conflito de nome: o Python está importando o próprio arquivo. A correção é renomear para app.py e rodar streamlit run app.py.

        Por que o nome sombreia o pacote

        Quando você executa um script, o diretório dele entra no sys.path. Se existe streamlit.py na pasta, import streamlit pode resolver para o arquivo local antes do pacote instalado. É um erro clássico de nome de módulo. Renomear é a solução mais simples.

        10. Plano B: rodar sem Supabase

        Para uma demo sem internet, use o ExtratorFalso dos testes ou crie um DataFrame em memória. Exemplo mínimo:

        import pandas as pd
from gerenciador_filas import GerenciadorFilas

df = pd.DataFrame([
    {"nome": "S1", "nivel_prioridade": 0, "motivo": "80+", "status": "aguardando",
     "data_chegada": "2026-01-01T09:00:00"},
    {"nome": "P1", "nivel_prioridade": 1, "motivo": "PCD", "status": "aguardando",
     "data_chegada": "2026-01-01T09:01:00"},
    {"nome": "C1", "nivel_prioridade": 2, "motivo": "convencional", "status": "aguardando",
     "data_chegada": "2026-01-01T09:02:00"},
])

g = GerenciadorFilas()
g.carregar_fila(df)
for _ in range(3):
    c = g.chamar_proximo()
    print(c.nome, c.nivel_prioridade.name)

        Isso não prova a integração com o banco, mas prova o algoritmo na frente da banca sem depender de rede.

        12. Limpeza e cuidados

        Para não deixar dados de teste no projeto:

        -- no SQL Editor do Supabase
DELETE FROM atendimentos;
DELETE FROM clientes_fila;

        Não apague as tabelas tipo_prioridade e motivo_prioridade se quiser manter o seed. Se for recriar tudo, rode o setup_supabase.sql novamente; ele é idempotente para tabelas e políticas, mas os INSERT usam ON CONFLICT.
